# Scene Catalog

Default scenes for OKR planning, in teaching order within each difficulty level.
Use the slug as the scene's file name. The learner's own situations (from the vision) come first;
add them as new scenes when they are not in this list.

- **Difficulty 1** (plan months 1–2): one goal, predictable lines.
- **Difficulty 2** (months 3–4): more turns, numbers and details, some choices.
- **Difficulty 3** (months 5–6): problems, negotiation, explaining and persuading.
